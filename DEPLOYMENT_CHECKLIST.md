## 🚀 GitHub Pages Deployment

### Step 1: Create Repository
- [ ] Create new GitHub account (if needed)
- [ ] Go to github.com/new
- [ ] Repository name: `song-dedication-qr-journey` (or your choice)
- [ ] Description: "A romantic song dedication QR journey"
- [ ] Select "Public"
- [ ] Click "Create repository"

### Step 2: Initialize Git Locally
```bash
cd path/to/sana_surprise

# If git isn't initialized yet:
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit: Song Dedication QR Journey"

# Rename main branch (if needed)
git branch -M main

# Add remote
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# Push to GitHub
git push -u origin main
```

### Step 3: Enable GitHub Pages
- [ ] Go to repository settings
- [ ] Scroll to "GitHub Pages" section
- [ ] Branch: select `main`
- [ ] Folder: select `/ (root)`
- [ ] Click "Save"
- [ ] Wait 1-2 minutes for deployment

### Step 4: Verify Deployment
- [ ] Visit: `https://YOUR_USERNAME.github.io/REPO_NAME/`
- [ ] Index page loads correctly
- [ ] All links work
- [ ] Pages and audio load properly
- [ ] Mobile view responsive

### Materials Needed:
- [ ] Cardstock or quality paper (200-300 gsm recommended)

- [ ] Scissors for cutting

## ⚠️ Troubleshooting

### If QR codes don't work:
- [ ] Check URL is spelled correctly
- [ ] Verify GitHub Pages is enabled
- [ ] Wait 2-3 minutes for deployment
- [ ] Try generating new QR codes
- [ ] Test URL directly in browser first

### If pages won't load:
- [ ] Check internet connection
- [ ] Verify GitHub Pages URL structure
- [ ] Clear browser cache
- [ ] Try incognito/private browsing
- [ ] Check repository is public

### If audio won't play:
- [ ] Verify MP3 files are in `songs/` folder
- [ ] Check file names are correct: `song1.mp3`, etc.
- [ ] Test MP3 files locally first
- [ ] Check file format (must be MP3)
- [ ] Verify file size isn't too large

### If animations don't work:
- [ ] Update browser to latest version
- [ ] Check JavaScript is enabled
- [ ] Clear browser cache
- [ ] Test in different browser
